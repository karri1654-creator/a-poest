# «А поесть?» — веб-сервис доставки еды

Учебный проект курсовой работы: адаптивный сайт доставки готовой еды с каталогом блюд, корзиной, личным кабинетом покупателя и панелью администратора. Все данные хранятся в единой базе данных приложения в формате JSON (`database.json`) — сервер и сборка не требуются.

## Стек технологий

- **HTML5** — семантическая разметка страниц.
- **CSS3** — переменные, Flexbox, CSS Grid, адаптивная вёрстка, анимации.
- **JavaScript (ES6+)** — ванильный JS без фреймворков: рендеринг, фильтры, корзина, модальные окна, синхронизация данных.
- **JSON (database.json)** — структурированное хранение и обмен данными блюд, заказов, обращений, пользователей и адресов.
- **Google Fonts (Inter)** — фирменная типографика.

## Роли и возможности

### Покупатель

- Просматривает главную страницу и каталог блюд без авторизации.
- Ищет блюда по названию и составу, фильтрует по категории, приёмам пищи, цене и предпочтениям.
- Добавляет блюда в корзину, меняет количество и удаляет позиции — данные сохраняются в единой базе данных приложения (JSON / `database.json`).
- Оформляет заказ после входа или регистрации: гость перенаправляется на `auth.html`, а после авторизации возвращается в каталог к сохранённой корзине.
- Выбирает адрес доставки, видит статус и состав заказа.
- Открывает личный кабинет: активный заказ, история, адреса, настройки профиля.
- Отправляет обращения в поддержку через карточку заказа или ссылку «Поддержка» в футере.
- Видит статус своих обращений («Ожидает ответа» / «Отвечено») и ответ администратора.

### Администратор

- Входит в аккаунт администратора и открывает панель по адресу `admin.html`. Гостей и покупателей панель перенаправляет на страницу входа.
- Вкладка **«Заказы»** — просмотр, поиск, фильтрация и смена статуса заказа.
- Вкладка **«Блюда»** — добавление, редактирование, скрытие блюд из витрины.
- Вкладка **«Обращения»** — список заявок покупателей, карточка вопроса и отправка ответа. После ответа статус меняется на «Отвечено», а покупатель видит ответ в личном кабинете.
- Вкладка **«Настройки»** — параметры кухни (режим работы, бесплатная доставка от 900 ₽) и сброс всех демо-данных к исходным.

Для входа откройте `auth.html` и введите телефон или email вместе с паролем. Эти же демо-данные показаны в подсказке под формой входа. Регистрация нового покупателя открывается по кнопке «Зарегистрироваться»: имя — минимум 2 буквы, пароль — минимум 6 символов, телефон или email должны быть корректными и ещё не использоваться в базе.

После входа покупатель попадает в `profile.html`, администратор — в `admin.html`. Если перед авторизацией был оформлен заказ, пользователь возвращается в `catalog.html` к сохранённой корзине. Повторное открытие `auth.html` с активной сессией сразу перенаправляет в соответствующий кабинет.

## Структура данных JSON (database.json)

| Ключ | Назначение |
| --- | --- |
| `apoest_dishes` | Блюда каталога |
| `apoest_orders` | Заказы покупателей |
| `apoest_tickets` | Обращения в поддержку |
| `apoest_registered_users` | Зарегистрированные пользователи |
| `apoest_user` | Текущий пользователь |
| `apoest_addresses` | Сохранённые адреса |
| `apoest_active_address` | Активный адрес доставки |
| `apoest_cart` | Корзина |
| `apoest_cart_owner` | Владелец корзины |
| `apoest_active_order` | Последний активный заказ |
| `apoest_redirect_after_auth` | Куда вернуть пользователя после входа или регистрации |
| `apoest_initialized` | Флаг первичной инициализации |

Кнопка **«Сбросить демо-данные к исходным»** во вкладке «Настройки» удаляет все ключи `apoest_*` и перезагружает страницу: блюда, заказы, обращения, адреса и два демо-пользователя создаются заново.

## Запуск

Достаточно открыть `index.html` в браузере. Для корректной работы шрифтов и удобной проверки рекомендуется локальный сервер:

```bash
python -m http.server 8000
```

После запуска откройте `http://localhost:8000/`.
